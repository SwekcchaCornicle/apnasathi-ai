# Local QA checklist

- Audit branches, pull requests, dependencies, routes, models and migrations.
- Baseline backend and infrastructure tests and the frontend build.
- Verify public Cognito flows, JWT validation, language and session behavior.
- Verify authenticated chat, mobile history, voice, intent routing, shopping and account isolation.
- Run PostgreSQL migrations and semantic cache tests with LLM call counts.
- Run Docker, startup and CDK checks. Record performance evidence and release blockers.
